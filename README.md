# SMARTTOOLS AI — publication gratuite sur Vercel
1. Créez un compte gratuit sur github.com, puis un dépôt et envoyez-y ces fichiers (bouton « Add file > Upload files »).
2. Sur vercel.com : « Add New > Project », choisissez le dépôt, laissez les réglages par défaut, « Deploy ».
3. (Optionnel, pour une vraie IA) Vercel > Settings > Environment Variables : ajoutez ANTHROPIC_API_KEY (clé créée sur console.anthropic.com — l'API est PAYANTE à l'usage). Puis « Redeploy ».
   Sans clé, le site affiche un canevas local clairement étiqueté « pas une IA ».
4. Remplacez contact@example.com dans public/index.html (const CONTACT) par votre adresse.
